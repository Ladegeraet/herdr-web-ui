### Added
- Chat annotations: select text in an agent's or your own chat message, press Comment (or `C`) and
  write a note. The notes wait as chips in one sideways-scrolling row over the message box, where
  each can be edited or removed (its count holds Clear all), and go to the agent with the next
  message you send, after what you typed, as a "Message Feedback" block shaped like Plannotator's.
- A sent message shows its comments as small cards under what you typed, not as the Markdown the
  agent receives; three or more fold into one row. Tapping a card's quote scrolls to that passage
  and lights it briefly.
- The passages you commented on are marked with a solid tint in the accent color, stronger while
  the comment waits and calmer once sent. Each passage is remembered by where it stood in the
  message, so every comment of a message is marked, including passages across file paths, inline
  code and list items, and words that repeat are never marked in the wrong place.
