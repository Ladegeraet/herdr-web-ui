### Added
- Chat annotations: select text in an agent's or your own chat message, press Comment (or `C`) and
  write a note. The notes wait as chips in one sideways-scrolling row over the message box, where
  each can be edited or removed (its count holds Clear all), and go to the agent with the next
  message you send, after what you typed, as a "Message Feedback" block shaped like Plannotator's.
